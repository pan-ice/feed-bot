# 🍞 投喂插件

MaiBot 投喂插件 — 签到积分 + 商店道具 + 投喂Bot + 定时求投喂。

## 功能

- **签到系统**：每日签到获取积分，连续签到有额外奖励
- **积分系统**：记录每个用户的积分余额
- **商店系统**：全局商店（Bot管理员管理）+ 群内商店（群管理员管理）
- **投喂系统**：用道具投喂Bot，触发LLM生成的趣味回复
- **Bot属性**：饱食度/好感度随投喂变化，属性衰减触发求投喂
- **定时求喂**：Bot定时在群中撒娇求投喂

## 命令列表

### 用户命令
| 命令 | 说明 |
|------|------|
| `/签到` | 每日签到获取积分 |
| `/积分` | 查看积分余额 |
| `/积分排行` | 查看本群积分排行 |
| `/商店` | 查看可购买道具 |
| `/购买 <道具名>` | 购买道具放入背包 |
| `/背包` | 查看背包道具 |
| `/投喂 <道具名>` | 投喂Bot |
| `/投喂记录` | 查看投喂历史 |
| `/bot状态` | 查看Bot饱食度/好感度 |
| `/投喂排行` | 查看本群投喂排行 |

| 命令 | 说明 |
|------|------|

| `/投喂管理 授权 <群号> <QQ号>` | 授权群管理员 |
| `/投喂管理 取消授权 <群号> <QQ号>` | 取消群管理员 |

### 群管理员命令
| 命令 | 说明 |
|------|------|
| `/投喂管理 群上架 <名称> <价格> [emoji] [描述]` | 上架群内道具 |

## 配置说明

见 `config.toml`，主要配置项：
- `admin.admin_users`：Bot管理员QQ号列表
- `sign.base_points`：签到基础积分
- `bot_attr.*`：Bot属性相关配置
- `filter.*`：黑白名单和触发控制
- `llm.*`：LLM回复生成配置

## 安装

将插件目录放置在 MaiBot 的 `plugins/` 目录下即可。
