# 🍞 投喂插件

MaiBot 投喂插件 — 签到积分 + 商店道具 + 投喂Bot + 定时求投喂。

## 功能

- **签到系统**：每日签到获取积分，连续签到有额外奖励
- **积分系统**：记录每个用户的积分余额
- **商店系统**：全局商店（Bot管理员管理）+ 群内商店（群管理员管理）
- **投喂系统**：用道具投喂Bot，触发LLM生成的趣味回复，饱食度满时无法继续投喂
- **Bot属性**：饱食度随投喂变化，不同道具增加的饱食度不同，属性衰减触发求投喂
- **定时求喂**：Bot定时在群中撒娇求投喂

## 配置说明

编辑 `config.toml` 进行配置，修改后支持热重载。

### `[plugin]` 插件基础

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enabled` | bool | `true` | 是否启用投喂插件 |
| `config_version` | string | `"1.0.1"` | 配置版本号 |

### `[admin]` 管理员

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `admin_users` | list[str] | `[]` | Bot管理员QQ号列表，拥有所有管理员权限 |

```toml
[admin]
admin_users = ["123456789", "987654321"]
```

### `[sign]` 签到

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `base_points` | int | `10` | 每次签到获得的基础积分 |
| `consecutive_bonus` | int | `5` | 连续签到每天额外递增的奖励积分 |
| `max_consecutive_bonus` | int | `50` | 连续签到奖励积分上限 |

签到积分计算：`基础积分 + min((连续天数-1) × 递增奖励, 奖励上限)`

示例：`base_points=10, consecutive_bonus=5, max_consecutive_bonus=50`
- 第1天签到：10 + 0 = 10积分
- 第2天签到：10 + 5 = 15积分
- 第3天签到：10 + 10 = 20积分
- 第11天签到：10 + 50 = 60积分（达到上限）

### `[bot_attr]` Bot属性

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `initial_satiety` | float | `80.0` | 初始饱食度（0-100） |
| `satiety_decay_rate` | float | `0.5` | 饱食度每小时衰减量 |
| `seek_feed_threshold` | float | `30.0` | 饱食度低于此值时触发求投喂 |
| `seek_feed_cooldown` | float | `7200.0` | 求投喂消息冷却时间（秒，默认2小时） |
| `seek_feed_messages` | list[str] | (5条默认消息) | 求投喂消息列表，随机选择一条发送（LLM开启时优先用LLM生成） |

属性机制：
- **饱食度**：投喂道具时增加，增加量由道具的 `satiety_bonus` 决定，每个道具不同
- 饱食度上限为100，达到满饱食度时无法继续投喂
- 每小时自动衰减 `satiety_decay_rate`
- 饱食度低于 `seek_feed_threshold` 时，Bot 会定时在群中发送求投喂消息
- 求投喂消息从 `seek_feed_messages` 列表中随机选择一条发送；LLM 开启时优先用 LLM 生成更自然的回复

所有数据按群隔离：饱食度、积分、签到记录、背包道具、投喂记录，同一个QQ在不同群的数据互不影响。管理员命令在私聊中操作时需额外指定群号。

### `[filter]` 群配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `group_admins` | list[GroupAdminEntry] | `[]` | 授权群配置。**只有在列表中的群才会响应命令**，未配置的群静默忽略。运行时可通过 `/投喂管理 授权` 追加管理员，通过 `/投喂管理 群列表` 查看。 |

每个 `GroupAdminEntry` 包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `group_id` | str | 群号 |
| `admin_users` | str | 管理员QQ号，多个用逗号、空格或 \| 分隔 |

```toml
[[filter.group_admins]]
group_id = "123456789"
admin_users = "111, 222"
[[filter.group_admins]]
group_id = "987654321"
admin_users = "333 | 444"
```

### `[llm]` LLM回复

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enabled` | bool | `true` | 是否使用LLM生成投喂回复（关闭则使用 `fallback_reply`） |
| `model` | string | `""` | LLM模型名，留空使用MaiBot的replyer模型 |
| `temperature` | float | `0.8` | 生成温度，越高越随机（0.0-2.0） |
| `max_tokens` | int | `150` | 单次回复最大token数 |
| `fallback_reply` | string | `"谢谢你投喂我！好开心~"` | LLM不可用时的兜底回复 |

## 安装

将插件目录放置在 MaiBot 的 `plugins/` 目录下即可。

## 权限体系

| 权限级别 | 识别方式 | 可执行操作 |
|---------|---------|-----------|
| Bot管理员 | `config.toml` 中 `admin_users` 列表 | 所有管理员命令 + 全局商店管理 + 群内商店管理 + 授权群管理员 |
| 群管理员 | 通过配置 `group_admins` 或 `/投喂管理 授权` 设置 | 本群的群内商店管理（上架/下架群内道具）+ 授权/取消授权本群管理员 |
| 普通用户 | 默认 | 签到、查看积分、购买、投喂等用户命令 |
